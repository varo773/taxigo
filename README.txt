TaxiGo Website
================

پێکهاتەی فۆڵدەر:

TaxiGo/
├── index.html
├── TaxiGo.apk
└── README.txt

گرنگ:
- index.html بە href="TaxiGo.apk" لینککراوە.
- TaxiGo.apk دەبێت APK ـی ڕاستەقینەی پرۆژەکەت بێت و لە هەمان فۆڵدەری index.html دابنرێت.
- ئەگەر APK ـەکەت هێشتا ئامادە نییە، هیچ APK ـێکی ساختە دروست نەکراوە.
- دوای دانانی APK ـی ڕاستەقینە، index.html بکەرەوە و دوگمەی «دابەزاندنی TaxiGo APK» تاقی بکەرەوە.
